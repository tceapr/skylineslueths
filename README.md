# Skyline Sleuths

Skyline Sleuths is a classroom-friendly geography mystery game. Students study a skyline, reveal clues one at a time, and try to identify the city before the point value drops.

This prototype includes twenty city rounds using the local skyline images for Chicago, New York City, San Antonio, San Francisco, Seattle, Miami, St. Louis, Los Angeles, Dallas, Las Vegas, Washington, D.C., Nashville, Pittsburgh, Philadelphia, Boston, Denver, Salt Lake City, Cincinnati, New Orleans, and Minneapolis. The game is organized into 10-city levels, and more rounds can be added by editing the `cities` array in `script.js`.
