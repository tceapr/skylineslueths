# Skyline Sleuths

Skyline Sleuths is a classroom-friendly geography mystery game. Students study a skyline, reveal clues one at a time, and try to identify the city before the point value drops.

This prototype includes thirty city rounds using local skyline images. The game is organized into 10-city levels: Level 1 and Level 2 focus on U.S. skylines, and Level 3 focuses on international skylines including Paris, London, Sydney, Dubai, Toronto, Singapore, Tokyo, Rio de Janeiro, Cape Town, and Moscow. More rounds can be added by editing the `cities` array in `script.js`.
