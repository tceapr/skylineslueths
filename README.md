# Skyline Sleuths

Skyline Sleuths is a classroom-friendly geography mystery game. Students study a skyline, reveal clues one at a time, and try to identify the city before the point value drops.

This prototype includes six city rounds using the local skyline images for Chicago, New York City, San Antonio, San Francisco, Seattle, and Miami. More rounds can be added by editing the `cities` array in `script.js`.
